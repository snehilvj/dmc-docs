### Dash Mantine Components v3 (Powered by Mantine v9)

Released XXX XX, XXXX

DMC v3 is based on Mantine v9 and introduces new components, features, and improvements.

### Highlights

- New Marquee component for scrolling content.
- Over 100 new props and enhancements across the component library.
- Reorderable pills in MultiSelect and TagsInput, with drag-and-drop and keyboard support.
- New chart features, including brush selection, streamgraphs, and reference markers.
- Expanded date and time inputs, including range selection and durations over 24 hours.
- Input loading and success states, RichTextEditor table controls, and improved notifications and dropdown positioning.
- Improved responsive style performance.
### Migration Guide

DMC v3 includes breaking changes from Mantine v8 to Mantine v9. See the [Migration Guide](/migration) for instructions on updating your apps.

See the Mantine v9 changelogs for details of upstream changes: [9.0](https://mantine.dev/changelog/9-0-0/), [9.1](https://mantine.dev/changelog/9-1-0/), [9.2](https://mantine.dev/changelog/9-2-0/), [9.3](https://mantine.dev/changelog/9-3-0/), [9.4](https://mantine.dev/changelog/9-4-0/), [9.5](https://mantine.dev/changelog/9-5-0/), [9.6](https://mantine.dev/changelog/9-6-0/), and [9.7](https://mantine.dev/changelog/9-7-0/).

### Requirements

DMC v3 requires Dash >= 4.5 and React 19.

Set the React version in your app:

```python
import dash

dash._dash_renderer._set_react_version("19.2.4")

app = Dash()
```

Alternatively, set the environment variable:

```bash
REACT_VERSION=19.2.4 python app.py
```

#### New Marquee component

`Marquee` adds continuous scrolling animation for content.

#### Grid improvements

`Grid` now uses CSS `gap` instead of negative margins for column spacing. This removes the need for `overflow="hidden"` to prevent overflow caused by negative margins.

The `gutter` prop has been renamed to `gap`. New `rowGap` and `columnGap` props control spacing independently, and `GridCol` now supports `align` for vertical alignment.

#### SimpleGrid automatic columns

`SimpleGrid` now supports `minColWidth` to automatically adjust the number of columns based on available width. When set, `cols` is ignored. Use `autoFlow` to choose between `auto-fill` and `auto-fit`.

.. exec3::docs.simplegrid.auto_fill

`AppShell` now supports `mode="static"`, which places its elements in the normal document flow using CSS Grid instead of fixed positioning. The `layout="alt"` option places the navbar and aside at full height, with the header and footer adjusted between them.

### Inputs

#### Input loading state

All input components based on `Input` now support `loading` and `loadingPosition` props to display a loading indicator on either side of the input.

.. exec3::docs.textinput.loading

#### Input success state

Inputs based on `Input` and `Input.Wrapper` now support a `success` prop. It changes the input border color and can display a success message below it. When both `error` and `success` are set, `error` takes precedence.

A new `--mantine-color-success` CSS variable resolves to `teal-6` in light mode and `teal-8` in dark mode.

.. exec3::docs.textinput.success

Default props set on `Input` and `InputWrapper` in `theme.components` now cascade to derived components. This lets you configure shared properties such as `size`, `radius`, `variant`, and `withAsterisk` for all inputs, while retaining component-specific overrides.

`MultiSelect` and `TagsInput` now support `withPillsReorder` to reorder selected pills using drag-and-drop or the keyboard.

Use the arrow keys to move focus between pills. Press `Alt + ArrowLeft` or `Alt + ArrowRight` to reorder the focused pill. Focus follows the moved pill, allowing multiple moves without refocusing. Reordering is disabled when `disabled` or `readOnly` is set.

#### Number and boolean values

`Select`, `MultiSelect`, `SegmentedControl`, `CheckboxGroup`, and other group components now accept primitive values such as numbers and booleans, rather than only strings.

```python
dmc.Select(
    data=[
        {"value": 1, "label": "One"},
        {"value": 2, "label": "Two"},
        {"value": 3, "label": "Three"},
    ],
    value=2,
)
```

#### Clear section mode

Clearable inputs now support `clearSectionMode` to control how the clear button and `rightSection` are rendered:

- `"both"` (default): show both.
- `"rightSection"`: show only the supplied `rightSection`.
- `"clear"`: show only the clear button.

Supported components include `Select`, `Autocomplete`, `MultiSelect`, `TagsInput`, and the date and time input components.

.. exec3::docs.multiselect.clear_section_mode

#### Dropdown height

### Feedback

#### Notifications

Notifications now support swipe dismissal, auto-close progress, stacked layout, and priority:

- Swipe dismissal: dismiss notifications by dragging left or right, or by horizontal scrolling while hovering. These behaviors can be disabled on `NotificationContainer`, and individual notifications can opt out with `allowClose=False`.
- Auto-close progress: `withAutoCloseProgress` displays a progress line showing the time remaining before a notification closes. The line pauses with the timer and uses the notification color. Set a default on the container or override it for individual notifications.
- Stacked layout: `layout="stacked"` displays the latest notification in front, with older notifications peeking out behind it.
- Priority: notifications with higher `priority` take visible slots when the active notification limit is reached. Equal priorities retain insertion order. The default priority is `0`.

.. exec3::docs.notification.autocloseprogress

### Overlay

#### Tooltip arrow position

`Tooltip` now supports `arrowPosition="merge"`, which merges the arrow with the corresponding corner of the dropdown.

.. exec3::docs.tooltip.interactive-arrow
    :code: false

#### Stable dropdown positioning

`Popover` and components built on it now default to `preventPositionChangeWhenVisible=True`.

A dropdown chooses its position when opened and keeps that position until closed, even when scrolling, resizing, or changes to its content affect the available space. When neither side fits, it falls back to the preferred `position`.

To restore the previous behavior, set `preventPositionChangeWhenVisible=False` through `comboboxProps`:

```python
dmc.Select(
    comboboxProps={"preventPositionChangeWhenVisible": False},
    data=["React", "Angular", "Svelte"],
)
```

#### Interactive Tooltip

`Tooltip` now supports `interactive` to keep the tooltip open while the pointer moves from its target to the tooltip content. This allows users to interact with content such as links and supports WCAG 2.1 success criterion 1.4.13.

.. exec3::docs.tooltip.interactive_prop

#### Tooltip hideDetached

`Tooltip` now supports `hideDetached`, matching the behavior of `Popover`. It is enabled by default and hides the tooltip when its target is removed from the DOM, hidden with `display: none`, or scrolled out of a clipping container.

#### HoverCard accessibility and behavior

`HoverCard` now opens on keyboard focus, closes with `Escape` or an outside press, and is announced by screen readers. New props include `events`, `interactive`, `role`, and `returnFocus`.

On touch devices, `HoverCard` no longer opens on tap by default. Set `events={"focus": False, "touch": True}` and `closeOnEscape=False` to restore the previous behavior.

### Other new features

#### Theming and styling

A new `fontWeights` theme property controls font weights across components. The defaults are `regular=400`, `medium=600`, and `bold=700`, mapped to CSS variables.

To restore the previous medium weight of 500:

```python
dmc.MantineProvider(theme={"fontWeights": {"medium": 500}})
```

All Mantine components now support logical margin and padding props:

- `mis`: margin-inline-start
- `mie`: margin-inline-end
- `pis`: padding-inline-start
- `pie`: padding-inline-end

#### Responsive style performance

`MantineProvider` now supports `deduplicateInlineStyles`, enabled by default. With React 19, repeated responsive style values can share a single style tag instead of generating one for each component.

This can improve performance when rendering large lists with identical responsive style props. See [Responsive Styles](https://www.dash-mantine-components.com/responsive-styles) for details.

#### Additional component enhancements

- `ColorPicker` supports `name` and `hiddenInputProps` for uncontrolled form submissions.
- `ColorInput` supports `fullWidth` to make the dropdown match the input width.
- `JsonInput` supports `indentSpaces` to control JSON formatting indentation.
- `Collapse`, `NavLink`, and `AccordionPanel` support `keepMounted=False` to unmount collapsed content.
- `Stepper`, `Tabs`, and `Tree` support `keepMounted`.
- `Tabs` supports `keepMountedMode` to control how inactive panels are hidden when `keepMounted=True`. Use `"display-none"` to use `display: none` instead of the default `Activity` component.
- `Menu` submenus use a safe polygon when moving the pointer diagonally from a parent item to a submenu.
- `PasswordInput` supports `visibilityToggleFocusable` to include the visibility toggle in the keyboard tab order.
- `Checkbox` supports `readOnly` and `withErrorStyles`.
- `Spoiler` supports `showAriaLabel` and `hideAriaLabel` to customize screen reader labels.

### Breaking and behavior changes

- `TypographyStylesProvider` was renamed to `Typography`.
- `Grid.gutter` was renamed to `gap`. Use `rowGap` and `columnGap` for separate row and column spacing.
- `Spoiler.initialState` was renamed to `defaultExpanded`.
- `Text` and `Anchor` no longer accept the `color` prop. Use the `c` style prop instead.
- `Popover` and `Tooltip` no longer accept `positionDependencies`; it is no longer required.
- `Tree` no longer defines the `data-hovered` attribute for hover state. Apply hover styles with `&:hover` instead.
- The `PasswordInput` visibility toggle icon has changed.
- Notifications now pause the auto-close timer for all visible notifications when any notification is hovered. Set `pauseResetOnHover="notification"` to restore the previous behavior of pausing only the hovered notification.
- The default `theme.defaultRadius` changed from `sm` (4px) to `md` (8px).
- The `light` variant now uses opaque colors to improve contrast.
- The `mod` prop converts camelCase keys to kebab-case for data attributes.
- The default medium font weight changed from 500 to 600. See the `fontWeights` theme property above to customize it.
